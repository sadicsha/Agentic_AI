# Agentic AI Projects Portfolio

This repository contains four practical projects demonstrating how AI agents and automation can solve real-world problems.

## Projects

1. **n8n RAG Chatbot:** Answers questions using information from documents. Learn RAG, embeddings, and vector databases.
2. **n8n Multi-Agent Chatbot:** Uses AI agents for web research and analysis. Learn multi-agent workflows and Tavily Search.
3. **Zapier Payment Reminder Agent:** Automates payment reminders using Gmail and Google Sheets. Learn business process automation and tool integration.
4. **RetailWise AI Assistant:** Answers retail-related questions about pricing, discounts, inventory, and promotions. Learn prompt engineering and AI workflow design.

## What You Will Learn

- Agentic AI and workflow automation
- RAG and multi-agent systems
- AI tool integration
- Prompt engineering
- Business process automation
- Testing and troubleshooting AI workflows

## Objective

To explore how AI agents can combine language models, external tools, and structured workflows to improve productivity and support business decisions.
